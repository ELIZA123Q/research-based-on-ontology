## 边界

本包用于半导体产业、AI 芯片产品赛道、晶圆制造、设备材料、封测和供应链约束的本体优化。它只提供材料搜索和证据判断规则，不提供任何未经本轮材料验证的公司事实、行业份额、盈利结论或资产判断。

不覆盖消费电子整机、云计算服务、普通软件应用和非半导体电子元器件；除非 `base_ontology` 已明确把它们作为下游需求或资产暴露对象。

| 交易所问询回复、监管披露 | 验证业务真实性、收入确认、客户集中度、供应链风险和合规约束 | update、deprecate、reject |

## 专业状态变量

| 变量 | 口径 | 观察频率 | 典型来源 | 边界 |
|---|---|---|---|---|
| 半导体销售额/出货额 | 按全球、区域、品类或公司业务线统计的销售额 | 月度/季度/年度 | WSTS、SIA、公司财报 | 不得用单家公司收入直接代表行业周期 |
| 晶圆厂产能利用率 | 产能利用水平或稼动率 | 季度 | 公司财报、行业数据、调研材料线索 | 研报估算只能作线索，需注明估算 |
| 晶圆代工价格/ASP | 按制程、客户或产品类别的价格变化 | 季度/年度 | 财报、产业数据、客户披露 | 价格上涨不等于利润改善，需看成本和稼动率 |
| 资本开支 | 晶圆厂、封测、设备公司的 capex 或订单指引 | 季度/年度 | 公司公告、财报、行业协会 | 订单和收入存在滞后，不能直接同周期确认 |
| 设备订单/出货 | 设备企业新增订单、在手订单、收入确认和交付 | 季度 | 财报、公告、招投标 | 在手订单不等于当期收入 |
| 材料消耗/国产化率 | 硅片、光刻胶、电子特气、靶材等材料使用或替代比例 | 季度/年度 | 公司披露、客户认证、招投标 | 认证通过不等于规模放量 |
| 良率/制程节点成熟度 | 良率、制程节点、量产状态、先进封装能力 | 不定期/季度 | 公司披露、客户认证、技术材料 | 技术样品不能直接映射为商业化收入 |
| 库存周转/库存水位 | 芯片公司、分销商或下游客户库存 | 季度 | 财报、行业数据 | 下游库存和上游订单可能方向不同 |
| 研发费用率 | 研发费用/营业收入 | 季度/年度 | 财报 | 单期下降不能确认盈利拐点 |
| 毛利率 | 公司或业务线毛利率 | 季度/年度 | 财报 | 需结合产品结构、稼动率、价格和成本 |

## 专业传导检查

| 传导链 | 验证材料 | 滞后/边界 |
|---|---|---|
| 下游算力/消费电子/汽车需求 -> 芯片订单 -> 晶圆投片 -> 封测 -> 收入确认 | 客户采购、公司订单、财报、招投标、产业出货 | 订单到收入存在交付和验收滞后 |
| 晶圆厂资本开支 -> 设备订单 -> 设备交付 -> 收入确认 -> 毛利率变化 | 晶圆厂 capex、设备公司订单、财报 | capex 指引不等于设备企业当期收入 |
| 出口管制/政策约束 -> 供应受限 -> 国产替代验证 -> 客户导入 -> 收入兑现 | 政策原文、限制清单、客户认证、采购公告 | 政策受益必须有客户导入证据 |
| 存储/逻辑周期变化 -> 价格/库存 -> 稼动率 -> 毛利率 | 行业价格、库存、财报、产能利用率 | 价格和稼动率方向可能背离 |
| 先进封装/HBM 需求 -> 设备材料需求 -> 供应链瓶颈 -> 交付能力 | HBM 供应链披露、设备/材料公告、客户验证 | 热点主题不能替代订单或认证证据 |

## 业务结构关系补齐检查

以下检查只用于发现应补关系和材料缺口，不直接提供事实关系。关系是否写入 `optimized_ontology.relations`，必须以本轮材料、已有端点对象和核心 schema 为准。

| 检查对象 | 优先关系 | 需要验证的材料 |
|---|---|---|
| 设备/材料 -> 晶圆制造 -> 封装测试 -> 下游应用 | `segmentConnectsToSegment.chainRelationType` | 行业协会材料、公司年报、产品手册、采购/销售披露、产业链资料 |
| EDA/IP、设计、AI 加速芯片、HBM、先进封装之间的依赖、互补或竞争 | `productRelatesToProduct.productRelationType` | 产品说明、技术白皮书、客户验证、订单或认证材料 |
| 硅片、光刻胶、电子特气、靶材等材料与具体芯片、晶圆、封装产品的用途 | `materialUsedInProduct.usageRole` | 产品手册、工艺材料说明、客户认证、采购或招投标材料 |
| 材料路线之间的替代、前驱、工艺互补或产能竞争 | `materialRelatesToMaterial.materialRelationType` | 技术白皮书、认证材料、产能或采购披露 |
| 半导体公司之间的供销、代工、授权、合作、竞争或投资控制关系 | `companyRelatesToCompany.businessRelationType` | 年报客户/供应商披露、公告、授权协议、合作公告、监管披露 |
| 出口管制、政策约束、客户认证、产能投放等事件对变量的影响 | `eventAffectsVariable.effectDirection`、`eventRelatesToEvent.eventRelationType` | 政策原文、公告、监管文件、认证/采购进展、财报数据 |
| 资产对产业、环节、产品、材料或公司的暴露 | `assetExposedToTarget.exposureType` | 公司业务拆分、收入/毛利/订单披露、指数编制说明、资产说明书 |

方向规则：

- `segmentConnectsToSegment.chainRelationType=supplies_to` 的源端是供给方环节，目标端是被供给方环节。
- `companyRelatesToCompany.businessRelationType=supplies_to` 的源端是供应商，目标端是客户；`manufactures_for` 的源端是代工方，目标端是委托方。
- `productRelatesToProduct.productRelationType=depends_on` 的源端是依赖方，目标端是被依赖产品；`component_of` 的源端是部件或模块，目标端是上位产品。
- 证据只能说明“行业通常如此”时，不得创建具体公司、产品或材料关系；应写入下一轮材料缺口。

## 常见误判

- 把“国产替代空间大”直接写成公司收入增长。
- 把政策支持、出口管制或供应链约束直接写成资产利好。
- 把技术突破、样品发布、客户验证直接等同量产收入。
- 把在手订单、框架协议或意向订单直接等同当期收入。
- 把单期研发费用率下降直接等同盈利拐点。
- 把晶圆厂 capex 指引直接等同设备企业订单确认。
- 把新闻转载、研报图表或 AI 摘要作为正式状态观测。

## 降级/剔除规则

| 触发条件 | 默认动作 | 说明 |
|---|---|---|
| 缺少发布主体、发布时间或证据位置 | `deprecate` | 只能作为线索，不能作为正式证据。 |
| 只有研报预测或新闻转述支持变量观测 | `keep` 或 `deprecate` | 不得创建 `StateVariableObservation`。 |
| 技术进展没有客户认证、订单或量产材料 | `strengthen` 最高不超过弱强化 | 不得确认商业化。 |
| 上下游关系没有端点对象或业务关系材料 | `deprecate` | 不得硬连关系。 |
| 事件或政策影响对象泛化到全行业 | `deprecate` | 需补受影响对象、机制和边界。 |
| 材料明确证明对象不属于本研究范围 | `reject` | 例如业务不在半导体产业链或资产暴露不成立。 |

## 资产预期材料

半导体资产线索必须额外补充：

- 一致预期中的收入、毛利率、费用率、净利润或 capex 假设。
- 估值锚，如 P/E、P/S、EV/EBITDA、订单/收入倍数、同业可比，但不得生成目标价。
- 市场价格表现和成交状态，只能作为定价信号。
- 预期差来源：订单兑现、价格周期、政策边际变化、供应链约束解除或加剧。
- 反证材料：订单延迟、客户认证失败、价格下行、库存高企、毛利率恶化、政策限制扩大。

## 使用质量检查

- 是否优先回溯公告、财报、政策原文或可追溯数据。
- 是否把技术、订单、收入、利润和资产影响分层表达。
- 是否明确订单到收入、收入到利润、利润到资产影响之间的缺口。
- 是否将研报预测、评级、目标价和推荐语排除在事实观测之外。
- 是否为每条传导链保留缺失环节和下一轮材料需求。
