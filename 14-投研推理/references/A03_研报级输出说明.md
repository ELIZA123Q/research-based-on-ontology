# 研报级输出说明

## 一、输出目标

本文件只适用于 `full_report` 模式。投研推理 Skill 的默认输出不是完整研报，而是先完成基于当前本体基座的结构化本体推理，再按用户角色选择场景化表达。

当用户明确要求“完整研报”“研报级分析”“正式报告”或需要长文归档时，输出面向投研使用的专业中文分析报告。报告不是观点短评，而是基于证据化链路推理：先确认事实和本体基座，再检索对象与关系，最后形成分层影响判断。

用户要求机器可读时，按 `schemas/投研推理输出结构.json` 输出 JSON，其中 `scenario_output.mode` 应为 `full_report`。

## 二、报告结构

`full_report` 模式采用四段式结构，面向投研人员。正文控制在 800-1500 字，详情数据使用 `<details>` 标签折叠。至少包含以下部分：

### 第一段：身份背景

```markdown
> **本体**：{ontology_name} v{version}
> **报告**：投研推理报告
> **范围**：{scope_type} · {研究范围描述}
> **时间**：{生成时间}
```

### 第二段：结论概览

一句话先行结论 + 紧凑表格：

```markdown
## 结论

{一句话核心判断。例如："硅料价格环比上涨 12%，预计通过硅片成本传导至电池片盈利，传导链历史命中率 87%，但当前产能缓冲可能削弱传导幅度。"}

| 维度 | 结果 |
|------|------|
| 核心结论 | {方向判断，如"成本压力传导" / "影响有限" / "传导受阻"} |
| 置信度 | 🟢 高 / 🟡 中 / 🔴 低 |
| 主要影响层级 | {如"直接影响硅片毛利率，间接影响电池片排产"} |
| 反证风险 | 🟢 低 / 🟡 中 / 🔴 高 |
```

### 第三段：分析详情

按分析逻辑组织，每节先说结论再说推理过程。核心章节包括：

- **事件事实**：{事件/观点/研报的核心事实，附来源核验说明}
- **本体命中与差异**：{命中了哪些传导链和假设，本次与历史案例的关键差异在哪里，差异怎么影响结论}
- **核心推理链**：{从事件到影响的完整推理链路，标注历史命中率和传导时滞}
- **影响评估**：{分层说明直接影响、间接影响和边界风险}

<details><summary>数据逻辑详情 / 完整影响分层 / 情景分析 / 反证条件 / 跟踪指标</summary>

{详细数据逻辑与可量化指标}
{完整影响分层（直接 → 间接 → 潜在）}
{base / upside / downside 三种情景路径}
{反证条件：哪些数据出现会削弱或推翻链路}
{后续跟踪指标列表}

</details>

### 第四段：下一步

```markdown
## 下一步

| 优先级 | 跟踪项 | 说明 |
|-------|-------|------|
| 近期 | {1-2 周内需跟踪的关键信号} | {关联传导链和预期变化} |
| 中期 | {1-3 个月的验证节点} | {验证哪个假设或传导} |
| 长期 | {需要持续观察的结构性变化} | {可能的传导链失效条件} |
```

### 详细说明

链路推理模板、证据分层、数据逻辑要求和结论分级继续遵循以下章节的规范。

## 三、链路推理模板

研报级输出中的标准链路：

`新闻/事件 -> 受影响对象 -> 状态变量 -> 观测或待观测指标 -> 变量传导 -> 状态假设 -> 信号 -> 判断输出 -> 资产影响候选`

常见链路类型：

- 直接经营链：事件影响产品、订单、价格、产能、成本或销量。
- 产业链传导链：上游供给、价格或技术变化传导到中游和下游。
- 政策链：政策约束、支付端、准入、补贴、监管或采购规则变化影响变量。
- 竞争格局链：新产品、产能、份额或渠道变化影响竞争变量。
- 资产影响链：判断输出经过市场预期和估值锚，形成资产影响候选。
- 阻断链：技术验证失败、扩产延迟、订单取消、价格压力、良率不足、财务确认滞后或市场已充分定价削弱原假设。

## 四、证据分层

证据优先级：

1. 公司公告、财报、监管文件、政策原文、交易所文件、招投标、出口管制、海关和官方统计信息。
2. 行业协会、官方数据库、可追溯价格/销量/库存/订单/产能/良率/进出口数据。
3. 高质量媒体、券商研报、专家纪要。
4. 二次转载、社媒、未核验传闻。

事实、估算、预测、假设、判断、推荐语必须分开。预测和推荐语不能映射为客观状态观测。

## 五、数据逻辑要求

报告需要尽量给出可核验的数据逻辑：

- 基准：历史同期、上一季度、行业均值、公司过往水平或本体中的参考基线。
- 变化：同比、环比、绝对增量、份额变化、价格变化、渗透率变化或进度变化。
- 传导：变化如何影响收入、毛利率、费用率、现金流、订单、产能利用率、市场预期或估值锚。
- 滞后：政策、审批、订单、收入确认、利润确认、估值重估之间的时间差。
- 反证：哪些数据出现会削弱或推翻链路。

数据不足时，应输出“需要补证的数据”，不得用形容词代替量化逻辑。

## 六、结论分级

建议使用以下置信度：

- 高：事实来源可靠，链路完整，多源证据支持，关键变量已有观测。
- 中：事实可靠，链路基本完整，但财务或资产影响仍需后续数据验证。
- 低：事实或本体映射不充分，关键链路缺失，只能作为候选影响。

结论应说明“为什么不是更高置信度”，并列出下一验证点。

## 七、禁止项

- 不输出买入、卖出、增持、减持、持有等交易建议。
- 不输出目标价、收益率预测或仓位建议。
- 不把市场传闻当作事实。
- 不把新闻直接跳推为收入、利润、估值或股价影响。
- 不把当前本体基座中不存在的关系伪装为已检索到的关系。
