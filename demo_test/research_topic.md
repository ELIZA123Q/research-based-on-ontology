# 研究主题：碳酸锂价格波动对动力电池中游材料企业的影响

## 主题范围
- 产业链环节：上游锂资源 → 中游正极材料/电解液/隔膜 → 下游电池制造
- 聚焦环节：中游正极材料企业（磷酸铁锂 LFP、三元材料 NCM）
- 核心变量：碳酸锂现货价格、库存周期、长协 vs 现货采购比例、成本传导效率
- 时间范围：2023-2024

## 研究对象
1. 德方纳米（LFP 正极龙头）
2. 容百科技（三元正极）
3. 湖南裕能（LFP 正极）
4. 天赐材料（电解液）

## 核心问题
1. 碳酸锂价格下跌对正极材料企业毛利率的传导路径和滞后时间？
2. 不同类型正极材料（LFP vs 三元）的成本结构差异如何影响冲击程度？
3. 库存减值在价格下行周期中的触发条件和影响量级？
4. 长协锁价机制在碳酸锂价格单边下行时的有效性？

## 关键事件
- 2023年碳酸锂从50万/吨跌至10万/吨
- 2024年初碳酸锂价格低位震荡
- 主要正极材料企业年报/季报发布时间
