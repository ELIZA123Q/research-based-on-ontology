# 历史回放报告（模拟）

## 回放结果

### case_2023_crash
- 传导链验证：碳酸锂从50万跌至10万→正极材料企业库存减值大幅计提→毛利率恶化，传导链部分验证
- 阻断条件发现：长协锁价企业在价格下行初期损伤较小，但长协到期后续约价格下移导致滞后冲击
- 误触发发现：单纯"碳酸锂跌→毛利率跌"的传导忽略了"先期高价库存消耗→低价补库→毛利率修复"的反向路径

### case_2024_q1_recovery
- 传导链验证：碳酸锂低位震荡→企业毛利率逐步修复，验证了"库存减值出清后毛利率回升"路径
- 边界样本：天赐材料（电解液）受碳酸锂冲击弱于正极材料企业，验证了成本结构差异的重要性
