# 标的研究框架生成 Skill

## 定位

本 Skill 是面向业务用户的研究输出能力。输入是一个研究标的、研究问题、关键词、材料摘要或上游证据矩阵，输出是围绕单一标的的固定结构研究框架。

本 Skill 回答：围绕这个公司、行业、产品、产业链环节、政策主题、事件主题或资产标的，应研究什么、跟踪什么变量、用什么信号验证、什么条件推翻当前判断。

本 Skill 不负责大批量材料逐篇抽取。大量原始材料先交给 `投研材料本体化抽取 Skill` 生成候选研究资产和跨材料证据矩阵。

## 工作流程

1. 确定唯一主研究标的和标的类型。
2. 读取上游证据矩阵、用户材料摘要或用户提供的研究问题。
3. 补齐标的画像、研究触发点和核心分歧。
4. 将研究问题映射到状态变量、验证信号和反证条件。
5. 构造事件/变化到业务、财务、估值或市场预期的传导逻辑。
6. 输出估值与资产影响候选，只表达研究判断和预期差。
7. 输出当前判断、判断级别、成立条件、反证条件和后续跟踪重点。
8. 输出风险提示和质量边界。

## 通用研究输出要求

- 输出必须围绕一个主研究标的展开，并把行业、产品、客户、供给、需求、价格、成本、渠道、政策或技术变化映射到该标的。
- 当前研究触发点必须说明事件、市场关注点、核心分歧和为什么现在需要研究。
- 核心投资问题必须落到状态变量，状态变量必须可观察、可比较、可跟踪、可反证。
- 传导逻辑必须拆成 `触发/事件 -> 前置验证 -> 商业转化 -> 履约或兑现 -> 经营指标变化 -> 财务或资产影响 -> 市场预期变化`；缺失环节标记为待验证。
- 证据与验证信号必须区分支持、反证、跟踪和阻断，不得把单一信号写成完整结论。
- 阻断信号必须作用于状态假设或关键前提，不能直接替代判断输出；判断降级必须通过假设被削弱或阻断表达。
- 结论级别必须受证据等级约束；单来源、缺少历史样本或缺少反证检查时，只能形成候选判断。
- 估值与资产影响只能表达收入、利润、估值、市场预期差和可能反映路径，不输出买卖建议、目标价、收益率预测或仓位建议。
- 风险提示必须对应基本面、行业、估值和数据不确定性，并写明可观察的反证条件。

## 条件加载

- 入门使用者要求简明解释时，加载 `references/00_入门术语表.md`。
- 标的涉及半导体、设备、材料、晶圆厂、先进制程、AI 芯片、HBM、封测、EDA 或国产替代时，加载 `references/04_半导体标的研究校准.md`。

## 固定输出结构

标的研究输出固定包含：

1. 标的基本画像。
2. 当前研究触发点。
3. 核心投资问题。
4. 关键状态变量。
5. 证据与验证信号。
6. 传导逻辑。
7. 估值与资产影响。
8. 结论。
9. 风险提示。

不同标的类型的字段侧重点见 `references/03_标的研究输出模板.md`。

## 输出边界

- 每次输出只围绕一个主研究标的。
- 结论级别不能高于证据等级。
- 单来源材料只能支持单来源候选。
- 缺少历史样本的逻辑不能写成历史支持模板。
- 估值与资产影响不包含买卖建议、目标价、收益率预测、仓位建议或确定性股价判断。

## 入门模式

入门模式使用 `references/00_入门术语表.md`。

输出顺序：

1. 简明解释。
2. 固定结构研究框架。
3. 后续需要补充的材料和验证信号。
