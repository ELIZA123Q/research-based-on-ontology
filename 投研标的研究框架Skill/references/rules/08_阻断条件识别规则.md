# 08_阻断条件识别规则

## 目标

识别会削弱、限制或阻断候选传导逻辑的条件。

## 合格阻断条件

阻断条件应尽量可观察、可验证、可追溯。

示例：

| 不推荐表述 | 推荐表述 |
|---|---|
| 竞争格局恶化 | ASP 连续两个季度下行超过阈值 |
| 订单质量不好 | 订单确认后毛利率低于历史均值 |
| 需求不及预期 | 出货量连续低于预期区间 |
| 政策不及预期 | 政策细则未在预期窗口发布 |

## 输出要求

阻断条件应包含：

- 关联变量或传导逻辑。
- 条件描述。
- 可观察改写。
- 阈值或窗口，如可得。
- 来源证据。
- 当前状态：候选、待改写、待验证或剔除。

## 禁止事项

- 不得用情绪化或泛化表达直接作为阻断条件。
- 不得让单一弱信号直接阻断通用模板。
- 不得省略作用对象。
