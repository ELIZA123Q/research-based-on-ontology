# A02_Skill输入输出说明

## 一、输入总览

本 Skill 支持四类输入：关键词输入、材料输入、既有资产输入和输出约束输入。

输入不要求一次性完整。缺失字段不得编造，应在输出中标注“未提供”或“需补充”。

## 二、关键词输入

关键词输入用于自行收集材料和搭建初始投研框架。

建议字段：

| 字段 | 说明 |
|---|---|
| 关键词 | 行业、公司、产品、产业链环节、主题或政策词 |
| 研究范围 | 行业、区域、产品、应用场景、客户类型或时间范围 |
| 材料偏好 | 研报、公告、财报、政策、新闻、转写稿或产业数据 |
| 输出目标 | 标的研究输出、通用框架、投研模板卡片或质量检查 |

关键词输入的第一输出通常是材料收集计划和候选材料清单。
如果无法实际访问材料来源，应将收集状态标记为“仅规划收集”，不得把计划中的材料方向写成已经收集到的材料。

## 三、材料输入

材料输入用于本体化抽取和模板影响评估。

建议字段：

| 字段 | 说明 |
|---|---|
| 文档标题 | 材料标题 |
| 文档类型 | 研报、公告、财报、政策、新闻、转写稿、产业数据 |
| 作者或发布主体 | 作者、机构、公司或监管部门 |
| 发布时间 | 材料发布时间 |
| 业务时间 | 事件发生时间、财报期间或政策生效时间 |
| 原文内容 | 全文、摘要或文本片段 |
| 原始位置 | URL、文件路径、页码、段落、图表编号 |
| 覆盖对象 | 行业、环节、公司、产品、材料或资产 |

## 四、既有资产输入

既有资产用于判断新材料对通用模板的影响。

可包括：

- 已有通用投研框架。
- 已有状态变量库。
- 已有触发分类。
- 已有传导逻辑。
- 已有验证信号。
- 已有阻断条件。
- 已有抽取候选项。

如果没有既有资产，Skill 应将证据基础标记为“缺少上游证据矩阵”或“待多来源验证”。

## 五、输出约束输入

输出约束用于控制结果形态。

可包括：

- 是否需要 JSON。
- 是否围绕单一研究标的输出。
- 是否只输出框架摘要。
- 是否需要证据位置。
- 是否需要质量检查。
- 是否需要平台字段映射。
- 是否需要入门模式简明解释。
- 是否需要投研模板卡片。

## 六、输出总览

本 Skill 的主要输出包括：

| 输出 | 用途 |
|---|---|
| 标的研究输出 | 围绕一个研究标的形成固定结构研究输出 |
| 通用投研框架 | 从多材料归纳行业或主题的基础研究框架 |
| 投研模板卡片 | 将证据充分的候选逻辑沉淀为可复用模板 |
| 质量检查 | 检查输出是否可展示、可追溯、可沉淀 |
| 输出沉淀计划 | 标明可保留、需补充、需专家校准或应剔除的内容 |

## 七、输出底线

所有输出必须尽量保留：

- 来源文档。
- 发布时间。
- 证据位置。
- 候选状态。
- 材料来源数量。
- 历史样本数量。
- 历史依据或缺口。
- 置信度或不确定性。
- 降级、剔除或待验证原因。

所有输出必须显式保留研究链条中的已验证环节和缺失环节：

- 触发或事件。
- 前置验证。
- 商业转化。
- 履约或兑现。
- 经营指标变化。
- 财务或资产影响。
- 市场预期变化。
- 反证、阻断或待验证条件。

所有输出不得包含：

- 买卖建议。
- 目标价。
- 仓位建议。
- 确定性收益判断。
- 未经专家确认的正式入库结论。
