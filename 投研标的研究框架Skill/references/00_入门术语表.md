# 00_入门术语表

本文件定义入门使用者所需的基础术语解释。解释文本只辅助理解，不改变本体定义。

| 术语 | 简明解释 | 使用边界 |
|---|---|---|
| 研究标的 | 本次研究围绕的对象，如公司、行业、产品、产业链环节、政策主题、事件或资产。 | 输出必须围绕一个明确标的展开。 |
| 状态变量 | 持续观察的研究维度，如订单、毛利率、库存、客户验证进度。 | “景气度好”“竞争改善”需要拆成可观察变量。 |
| 状态观测 | 某个时间点的事实或估算值，如“2025Q1 新签订单同比增长 45%”。 | 预测、目标价、评级不是客观观测。 |
| 触发点 | 让研究问题变得重要的新信息，如财报披露、政策发布、订单公告。 | 主题热度不是基本面验证。 |
| 传导逻辑 | 一个变量影响另一个变量的路径，如订单增长影响收入确认。 | 表述必须包含变量、窗口和边界条件。 |
| 验证信号 | 后续用于确认逻辑的事实，如合同负债、收入确认、毛利率。 | 表述必须包含来源、频率和预期方向。 |
| 阻断条件 | 原逻辑失效或变弱的条件，如交付延期、毛利率下滑。 | 条件需要可观察。 |
| 单来源候选 | 一份材料支持的线索。 | 不能作为通用模板。 |
| 多来源候选 | 多个独立原始来源支持的线索。 | 仍需历史样本和反证检查。 |
| 历史支持模板候选 | 多来源支持，且历史案例中反复出现并具备失效边界的模板候选。 | 仍需专家校准。 |

## 入门模式输出

入门模式先给简明解释，再给结构化输出。

- 研究标的是什么。
- 当前为什么需要研究。
- 最关键的变量是什么。
- 后续用什么信号验证。
- 什么情况会推翻当前判断。
- 下一步补充什么材料。
