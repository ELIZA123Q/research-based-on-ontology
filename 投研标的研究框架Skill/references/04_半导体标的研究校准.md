# 04_半导体标的研究校准

本文件用于半导体公司、行业、产品、产业链环节或资产标的研究框架生成。

本文件只补充半导体行业的画像字段、状态变量和传导映射。通用研究输出要求以 `SKILL.md` 为准。

## 标的画像补充项

半导体标的画像优先补齐：

- 所在环节：设计、制造、封测、设备、材料、零部件、EDA/IP。
- 产品类别：设备类型、材料品类、芯片类型、工艺平台或封装形式。
- 客户结构：晶圆厂、封测厂、设计公司、云厂商、汽车/工业客户。
- 收入结构：产品线、区域、客户、节点或应用场景。
- 利润来源：毛利率、费用率、规模效应、产品结构、国产化率。
- 竞争格局：海外龙头、国内同类厂商、替代技术路线。
- 所处周期：上行、下行、库存去化、补库、产能扩张或结构分化。
- 关键外部变量：晶圆厂 capex、终端需求、出口管制、客户验证、价格和库存。

## 核心研究问题

半导体标的常见问题：

- 订单增长能否转化为收入确认。
- 客户验证能否转化为批量采购。
- 国产替代能否转化为份额提升。
- 晶圆厂资本开支变化如何影响订单。
- 产品结构变化是否改善毛利率。
- 出口管制或供应链限制是否改变竞争格局。
- 周期复苏是否已经反映在价格、库存和产能利用率中。
- 当前市场预期已经反映到哪一层：主题、订单、收入、利润还是估值。
- 反证信号出现时，原判断应降级到什么状态。

## 关键状态变量

| 环节 | 关键状态变量 |
|---|---|
| 设备 | 新签订单、在手订单、合同负债、客户验证进度、发出商品、验收、收入确认、订单毛利率 |
| 材料 | 出货量、ASP、单耗、客户认证、批量供货、国产替代份额、产能利用率、原材料成本 |
| 设计 | sell-in、sell-through、渠道库存、ASP、产品迭代、客户导入、毛利率、费用率 |
| 制造 | 稼动率、资本开支、良率、晶圆价格、先进制程产能、客户结构、折旧压力 |
| 封测 | 产能利用率、先进封装渗透率、订单能见度、价格、毛利率、资本开支 |
| EDA/IP | 授权数量、续费率、客户覆盖、节点覆盖、工具验证、研发费用率 |

## 传导校准

- 订单增长到收入确认：必须验证交付、验收、合同负债和发出商品。
- 客户验证到订单：必须验证验证阶段、客户类型、复购或批量采购。
- 收入增长到利润改善：必须验证毛利率、费用率和订单结构。
- 国产替代到份额提升：必须验证中标占比、客户导入数量和收入占比。
- 周期复苏到资产影响：必须验证库存、价格、稼动率和资本开支。
- AI/HBM/先进封装主题到公司兑现：必须验证具体产品、客户、产能、订单、收入占比和单耗变化。
- 出口管制到国产替代：必须验证受限对象、替代窗口、客户导入、订单和交付能力。

## 研究框架模板

### 设备公司

- 核心问题：订单是否真实、交付是否按期、毛利率是否兑现。
- 验证链：客户验证 → 中标/订单 → 合同负债/发出商品 → 验收 → 收入确认 → 毛利率。
- 反证链：订单增长但合同负债不增、发出商品无法转收入、毛利率低于历史均值。

### 材料公司

- 核心问题：认证是否转为批量供货，单耗和 ASP 是否支撑收入。
- 验证链：客户认证 → 小批量供货 → 多客户导入 → 收入占比 → 毛利率。
- 反证链：认证周期拉长、客户导入单一、原材料成本上行、ASP 下行。

### 设计公司

- 核心问题：终端需求是否真实，库存是否健康，新品是否改善 ASP 和毛利率。
- 验证链：终端需求 → sell-through → 渠道库存 → sell-in → ASP/毛利率。
- 反证链：渠道库存高企、价格下行、新品放量低于预期。

### 制造和封测

- 核心问题：稼动率修复是否可持续，资本开支和折旧压力是否匹配需求。
- 验证链：终端需求 → 订单/排产 → 稼动率 → 价格 → 毛利率。
- 反证链：补库结束、价格下行、折旧压力上升、客户砍单。

## 风险边界

- 订单质量低于预期。
- 验证周期拉长。
- 毛利率低于历史均值。
- 晶圆厂资本开支下修。
- 海外管制扩大。
- 国产替代进度低于市场预期。
- 估值已提前反映短期催化。
- 库存周期和需求周期错配。
- 技术节点或产品平台无法跨客户复用。
- 供应链关键零部件、软件或材料受限。
