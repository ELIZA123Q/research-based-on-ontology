# 02_来源文档建档规则

## 目标

将输入材料登记为可追溯的来源文档，支撑后续抽取、质量检查和资产沉淀。

## 建档字段

每份材料应尽量记录：

| 字段 | 说明 |
|---|---|
| 文档标题 | 原始标题 |
| 文档类型 | 研报、公告、财报、政策、新闻、转写稿、产业数据 |
| 作者或发布主体 | 机构、公司、监管部门或作者 |
| 发布时间 | 文档发布时间 |
| 业务时间 | 事件发生时间、财报期间或政策生效时间 |
| 来源形态 | 原始 PDF、官网页面、券商页面、转载页面、AI 摘要 |
| 来源可靠性 | 高、中、低 |
| 覆盖对象 | 行业、环节、公司、产品、资产 |
| 原始位置 | URL、文件路径、页码、段落、图表编号 |
| 原始事实来源 | 该材料依赖的最早事实来源，如公司公告、财报、政策原文、调研纪要 |
| 材料用途 | 抽取、框架搭建、反证、背景或待核验 |

## 可靠性判断

- 高：官方公告、财报、政策原文、原始研报 PDF、公司官网正式材料。
- 中：券商页面、权威媒体、行业协会、可追溯转载。
- 低：无原文链接转载、摘要、社交媒体片段、AI 总结。

## 缺失处理

缺少标题、发布时间、来源位置或发布主体时，应显式标注缺口，不得补造。

## 禁止事项

- 不得删除原文证据。
- 不得用系统录入时间替代业务时间。
- 不得将低可靠来源作为唯一关键证据。
- 不得把多篇引用同一原始事实来源的材料当作多个独立来源。
