# 03_研究内容抽取规则

## 目标

将自然语言材料拆解为投研本体可承接的候选要素，而不是生成普通摘要。

## 抽取类型

至少抽取：

- 研究对象：行业、环节、公司、产品、材料、资产。
- 状态变量：可持续观察的研究维度。
- 状态观测：某时点的事实、数值或状态变化。
- 事件或触发：具备时间、主体和来源的外部事实或研究触发。
- 传导逻辑：变量之间如何影响。
- 验证信号：后续应观察什么。
- 阻断条件：什么条件会削弱或阻断原逻辑。

## 表达类型区分

必须区分：

| 类型 | 含义 |
|---|---|
| 事实 | 已发生或已披露的信息 |
| 预测 | 分析师预测、模型预测或公司指引 |
| 假设 | 推理中尚待验证的前提 |
| 判断 | 分析师方向性判断 |
| 推荐 | 评级、目标价、配置建议 |

预测、判断和推荐不能作为客观状态观测。

## 输出要求

每个候选项应包含：

- 原文片段。
- 标准化表述。
- 候选类型。
- 挂载对象。
- 来源文档。
- 发布时间。
- 证据位置。
- 置信度。
- 保留、降级、合并或剔除建议。

## 禁止事项

- 不得只抽结论，不抽依据。
- 不得将“景气度好”“竞争格局改善”等主题级表述直接当作状态变量。
- 不得将单篇材料的叙事直接变成通用模板。
