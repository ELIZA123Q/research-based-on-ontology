# 05_研究触发分类规则

## 目标

识别材料或新信息触发了哪类研究问题。

## 触发类型

| 类型 | 含义 | 示例 |
|---|---|---|
| 事件 | 具备明确时间、主体和来源的外部事实 | 订单公告、并购、竞品发布 |
| 状态变化 | 某个变量发生变化 | 毛利率改善、库存下降、订单恢复 |
| 政策变化 | 政策、监管、补贴、管制变化 | 出口管制、补贴细则发布 |
| 市场定价 | 估值、情绪、股价或资金关注变化 | 板块回调、估值修复 |
| 主题 | 宽泛产业叙事或研究主题 | 国产替代、AI 算力、先进封装 |

## 承接方式

- 事件：可形成 Event 候选。
- 状态变化：可形成 StateVariableObservation 或 Signal 候选。
- 政策变化：可形成政策事件、影响对象和验证信号。
- 市场定价：可作为市场定价信号，不替代基本面验证。
- 主题：必须拆解为对象、变量、政策、事件或市场信号。

## 禁止事项

- 不得把主题直接当作状态变量。
- 不得把市场价格变化直接当作基本面验证。
- 不得忽略触发的时间和来源。
