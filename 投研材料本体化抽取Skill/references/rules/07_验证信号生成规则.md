# 07_验证信号生成规则

## 目标

为候选变量、传导逻辑和通用模板生成后续验证信号。

## 信号角色

| 角色 | 用途 |
|---|---|
| validation | 支持假设或传导成立 |
| tracking | 持续跟踪但不足以升级 |
| catalyst | 加速判断兑现 |
| weakening | 削弱原逻辑 |
| blocking | 阻断原逻辑 |

## 信号字段

验证信号应说明：

- 观察对象。
- 关联变量。
- 数据来源。
- 观察窗口。
- 预期方向。
- 对模板的作用。

## 示例

- 下一期财报收入确认。
- 合同负债变化。
- 毛利率是否低于历史均值。
- 应收账款是否异常增加。
- 客户验证进度是否推进。

## 禁止事项

- 不得只写“持续跟踪”。
- 不得没有观察窗口。
- 不得没有来源类型。
- 不得将弱线索直接设为 validation。
