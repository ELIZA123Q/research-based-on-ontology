# 12_输出沉淀规则

## 目标

判断 Skill 输出应如何保留、降级、补充或进入后续专家校准。

## 沉淀状态

| 状态 | 含义 |
|---|---|
| 可登记 | 可作为来源文档保留 |
| 可保留候选 | 可作为抽取候选项或模板候选 |
| 需补来源 | 缺少独立来源或证据位置 |
| 需专家校准 | 变量粒度、传导逻辑或阻断条件需专家确认 |
| 应降级 | 只能作为主题、标签、背景或单文档线索 |
| 应剔除 | 无来源、不可观察、重复或越界 |

## 可沉淀对象

- 来源文档。
- 研究对象候选。
- 状态变量候选。
- 事件或触发候选。
- 传导逻辑候选。
- 验证信号候选。
- 阻断条件候选。
- 通用模板候选。
- 质量检查记录。

## 禁止事项

- 不得把候选资产标记为正式入库。
- 不得删除失败或被否定的候选项。
- 不得只保存结论，不保存来源和原因。
