# 11_质量检查规则

## 目标

检查 Skill 输出是否可展示、可追溯、可复用和可沉淀。

## 检查项

| 检查项 | 通过标准 |
|---|---|
| 来源完整 | 有来源文档、发布时间和证据位置 |
| 对象明确 | 研究对象可识别 |
| 变量可用 | 状态变量可观察、可比较、可传导 |
| 触发清楚 | 触发类型、时间和主体明确 |
| 传导有效 | 传导落到变量层 |
| 信号具体 | 说明观察对象、来源和窗口 |
| 阻断可观察 | 阻断条件能改写为可观察条件 |
| 表达合规 | 不输出买卖建议、目标价或仓位 |
| 模板谨慎 | 单一来源不升格为高置信通用模板 |

## 输出

质量检查应输出：

- 通过或不通过。
- 问题清单。
- 修正建议。
- 是否可展示。
- 是否可沉淀。
- 是否需要专家校准。
