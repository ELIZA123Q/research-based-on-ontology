# 04_半导体材料抽取校准

本文件用于半导体行业材料抽取。触发词包括半导体、设备、材料、晶圆厂、先进制程、AI 芯片、HBM、封测、EDA、国产替代。

本文件只补充半导体行业的对象、变量和链条映射。通用抽取校准要求以 `SKILL.md` 为准。

## 重点对象

- 行业：半导体、半导体设备、半导体材料、晶圆制造、封测、设计。
- 环节：设计、晶圆制造、封测、前道设备、后道设备、材料、零部件、EDA/IP。
- 产品：刻蚀、薄膜沉积、清洗、量测、检测、离子注入、CMP、涂胶显影、炉管、光刻胶、靶材、特气、湿电子化学品、先进封装设备、EDA 工具、IP。
- 客户：晶圆厂、封测厂、头部设计公司、云厂商。
- 竞争对手：海外龙头、国内同环节厂商、替代技术路线。

## 来源优先级

关键事实按以下顺序取证：

1. 公司公告、财报、交易所问询回复、招股书、定期报告。
2. 客户公告、供应商公告、招标/中标公告、政策原文、海关或行业协会数据。
3. 可追溯券商研报、行业深度、公司深度、电话会纪要。
4. 新闻、访谈、会议转写、产业链调研片段。
5. 转载摘要、社交媒体、AI 摘要。

低优先级来源只能作为线索。关键状态观测必须回溯至原始事实来源。

## 订单口径

抽取订单相关内容时必须区分：

- 新签订单。
- 在手订单。
- 合同负债。
- 发出商品。
- 中标/框架协议。
- 客户验证或导入。
- 出货。
- 收入确认。

不得把“中标”“验证通过”“订单意向”“出货”“收入确认”混为同一状态观测。

订单链条按以下顺序拆分：

`客户验证 → 中标/框架协议 → 新签订单 → 在手订单 → 发出商品 → 验收 → 收入确认 → 回款 → 毛利率兑现`

材料只提到链条中某一环节时，只抽取该环节，不得自动补齐后续环节。

## 客户验证阶段

客户验证进度按阶段标记：

1. 送样或 Demo。
2. 客户测试。
3. 产线验证。
4. 小批量导入。
5. 重复订单。
6. 批量采购。

阶段不明确时标记为“验证阶段未提供”。

## 环节专用抽取口径

| 环节 | 重点变量 | 常见误判 |
|---|---|---|
| 设备 | 新签订单、在手订单、合同负债、发出商品、验收、收入确认、订单毛利率 | 把订单增长直接等同于利润改善 |
| 材料 | 客户认证、批量供货、单耗、ASP、原材料成本、产能利用率 | 把客户认证直接等同于份额提升 |
| 设计 | sell-in、sell-through、渠道库存、ASP、产品迭代、客户导入、毛利率 | 把出货增长误判为终端需求改善 |
| 制造 | 稼动率、晶圆价格、先进制程产能、良率、资本开支、客户结构 | 把短期稼动率修复误判为长期景气反转 |
| 封测 | 产能利用率、先进封装占比、订单能见度、价格、毛利率 | 把先进封装主题热度直接等同于公司收入兑现 |
| EDA/IP | 授权数量、续费率、客户覆盖、工具验证、节点覆盖、研发投入 | 把国产替代叙事直接等同于商业化放量 |

## 常见状态变量

| 主题 | 状态变量 |
|---|---|
| 订单 | 新签订单、在手订单、订单能见度、订单结构 |
| 交付 | 交付周期、验收进度、发出商品、收入确认节奏 |
| 盈利 | 毛利率、订单毛利率、费用率、产能利用率 |
| 客户 | 客户验证进度、客户集中度、复购率、头部客户导入 |
| 国产替代 | 国产设备中标占比、客户导入数量、替代环节、进口限制 |
| 周期 | 晶圆厂资本开支、产能利用率、库存水位、招标节奏 |
| 技术 | 制程节点、设备平台成熟度、良率、关键零部件自制率 |

## 传导链校准

| 叙事 | 合格拆分 |
|---|---|
| 订单高增，业绩改善 | 新签订单 → 在手订单/合同负债 → 发出商品/验收 → 收入确认 → 毛利率和费用率 → 利润 |
| 客户验证通过，国产替代加速 | 验证阶段 → 小批量导入 → 重复订单 → 批量采购 → 收入占比/份额 |
| 晶圆厂扩产，设备受益 | 晶圆厂 capex → 招标节奏 → 中标份额 → 新签订单 → 收入确认 |
| AI/HBM 需求高景气 | 终端需求 → HBM/先进封装产能 → 设备/材料订单 → 收入确认 |
| 出口管制利好国产替代 | 受限产品/客户 → 替代窗口 → 客户验证 → 国产厂商订单 |

## 反证与阻断信号

- 订单增长但合同负债不增。
- 发出商品增加但验收和收入确认延迟。
- 收入增长但毛利率低于历史均值。
- 客户验证停留在测试阶段，未进入重复订单。
- 晶圆厂 capex 下修或招标延后。
- 库存高企且 ASP 下行。
- 海外限制扩大到关键零部件、软件或客户。
- 国产替代只停留在政策表述，缺少中标、导入、收入或份额数据。

## 半导体材料抽取边界

- 卖方预测只作为 Signal 或假设依据，不作为状态观测。
- 公司指引需要标记为 guidance，不等同于已发生事实。
- 行业空间测算不等于公司收入观测。
- 国产替代叙事必须拆成客户导入、订单、中标占比、收入确认或份额变化。
- 出口管制必须拆成受限产品、受限客户、替代路径、验证窗口和阻断条件。
- AI、HBM、先进封装、Chiplet 等主题必须拆成具体产品、客户、订单、产能、单耗、价格或收入指标。
- “平台化能力”“技术领先”“产品竞争力提升”必须拆成可验证事实，如节点覆盖、客户数量、良率、复购、批量采购或份额变化。
