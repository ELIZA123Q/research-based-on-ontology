# 00_入门使用路由

本文件定义入门使用者的输入识别和最小输入模板。

## 路由规则

| 用户输入 | 执行模式 |
|---|---|
| “我有一份研报/公告/财报，帮我拆一下” | 单篇材料抽取 |
| “我有多篇材料，帮我看能沉淀什么” | 批量材料抽取 |
| “围绕某主题要收集哪些材料” | 材料清单整理 |
| “这份材料对已有逻辑有什么影响” | 模板影响评估 |
| “这个抽取结果靠谱不靠谱” | 质量检查 |

## 最小输入模板

用户只需提供以下信息：

```text
材料标题：
材料类型：
发布时间：
发布主体：
原文片段或文件路径：
证据位置：
我关心的问题：
```

缺失字段标记为“未提供”。不得补造标题、日期、发布主体或证据位置。

## 入门输出

入门输出先给三句话：

- 这份材料提供的核心事实。
- 这份材料能沉淀的研究资产。
- 这份材料还缺什么证据。

随后输出结构化结果。
