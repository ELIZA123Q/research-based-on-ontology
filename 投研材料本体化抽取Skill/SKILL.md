# 投研材料本体化抽取 Skill

## 定位

本 Skill 是投研资产生产入口。输入是一份或多份材料，输出是可追溯、可复核、可沉淀的候选研究资产。

本 Skill 回答：这份材料或这批材料提供了哪些对象、变量、观测、触发、传导、验证信号、阻断条件、历史样本和模板影响。

本 Skill 不输出标的研究框架，不生成资产影响结论，不给出买卖建议、目标价、收益率预测或仓位建议。

## 任务模式

| 模式 | 触发条件 | 输出 |
|---|---|---|
| `材料清单整理` | 用户给关键词或材料方向 | 材料收集计划、候选材料清单 |
| `单篇材料抽取` | 用户给一份材料 | 单篇材料本体化解读 |
| `批量材料抽取` | 用户给多份材料 | 多篇抽取结果、跨材料证据矩阵 |
| `模板影响评估` | 用户给材料和既有模板 | 新增、强化、修正、削弱、否定、待验证影响 |
| `质量检查` | 用户要求检查抽取结果 | 质量检查结果 |

## 工作流程

1. 登记来源文档，保留标题、发布主体、发布时间、来源形态、证据位置和原始事实来源。
2. 区分事实、估算、预测、假设、判断和推荐。
3. 抽取研究对象、状态变量、状态观测、事件或触发、传导逻辑、验证信号和阻断条件。
4. 逐条标记候选状态、来源证据、置信度、保留/降级/剔除建议。
5. 多材料输入时建立跨材料证据矩阵，按原始事实来源去重。
6. 判断候选逻辑属于单来源候选、多来源候选、历史支持模板候选或需补历史样本。
7. 输出质量检查，说明缺口和下一步补充材料。

## 通用抽取校准要求

- 抽取对象必须回到一个明确研究对象或研究范围，不能只沉淀宽泛主题词。
- 每条候选逻辑必须拆成 `触发/事件 -> 前置验证 -> 商业转化 -> 履约或兑现 -> 经营指标变化 -> 财务影响或资产影响线索` 的可核验链条；材料没有覆盖的环节标记为“需补充”，不得自动补齐。
- 状态变量必须可持续观察、可时间比较、可形成方向性假设，并能进入传导链。
- 验证信号必须说明验证对象、验证方向、数据来源和跟踪频率。
- 阻断条件和反证信号必须与状态变量或假设对应，不能只写成笼统风险。
- 任何从事件、政策、产品、客户、价格、产能、流量或供需变化直接跳到收入、利润、估值或资产表现的表述，必须降级为待验证候选。
- 同一逻辑在不同产业中应替换为对应链条，例如客户链、订单链、价格链、产能链、成本链、库存链、渠道链、政策链或流量链。

## 输出边界

- 单篇材料只能形成单来源候选。
- 多篇材料引用同一公告、财报或政策原文时，只计一个原始事实来源。
- 缺少历史样本时，不得标记为历史支持模板候选。
- 分析师预测、评级、目标价和推荐语不得作为客观状态观测。
- 市场价格变化可以作为市场定价信号，不替代基本面验证。

## 下游接口

下游 `标的研究框架生成 Skill` 可消费以下资产：

- `单篇材料本体化解读结构.json`
- `跨材料证据矩阵结构.json`
- `模板影响评估结构.json`
- `质量检查结构.json`

本 Skill 负责生产候选研究资产；下游 Skill 负责围绕研究标的组织最终研究输出。
